# MCP - Blue Team

## Wprowadzenie
Ta strona została stworzona dla członków niebieskiej drużyny, badaczy sztucznej inteligencji oraz entuzjastów defensywnej strony bezpieczeństwa MCP.
Znajdziesz tu narzędzia, zasoby i uwagi dotyczące ochrony serwerów Model Context Protocol.
