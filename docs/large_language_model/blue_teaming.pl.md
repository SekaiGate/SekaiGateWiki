# LLM - Blue Team

## Wprowadzenie
Ta strona została stworzona dla członków niebieskiej drużyny, badaczy sztucznej inteligencji oraz entuzjastów defensywnej strony bezpieczeństwa LLM.
Znajdziesz tu narzędzia, zasoby i uwagi dotyczące ochrony dużych modeli językowych (LLM).
