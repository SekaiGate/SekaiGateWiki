# LLM - Red Team

## Wprowadzenie
Ta strona została stworzona dla członków zespołów red team, badaczy sztucznej inteligencji oraz entuzjastów ofensywnych aspektów bezpieczeństwa LLM.
Znajdziesz tu narzędzia, ładunki i uwagi dotyczące testowania granic bezpieczeństwa dużych modeli językowych (LLM).
