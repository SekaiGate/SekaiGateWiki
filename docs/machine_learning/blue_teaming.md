# ML - Blue Team

Welcome to the **ML Blue Teaming Notes** – a curated collection of resources, tools, and best practices for defending against security threats in Large Language Models (MLs).  
This repository is dedicated to blue teamers, AI developers, security researchers, and anyone working to **protect ML systems** from malicious attacks, adversarial behaviors, and other security challenges.
