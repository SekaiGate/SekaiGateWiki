# Agenci AI

## Wprowadzenie

AI Agents to pojedyncze autonomiczne programy AI wykonujące określone zadania na podstawie promptów lub narzędzi. Ich bezpieczeństwo dotyczy przede wszystkim prompt injection, niewłaściwych działań, wycieków danych i nieautoryzowanych akcji wykonywanych przez agenta.
