# 🔐 Sekai;Gate Wiki

Sekai;Gate Wiki is the open documentation portal and knowledge base for Sekai;Gate - a project focused on AI security, red-teaming, blue-teaming, compliance, and frameworks. The goal of this wiki is to provide structured, community-driven reference material covering techniques, tools, regulations, and best practices in AI-centric security and risk management.

## 📖 Website documentation:
👉 https://sekaigate.github.io/SekaiGateWiki/

## 🚀 Overview

SekaiGateWiki provides:

- 🧪 Red Teaming resources — offensive security tools and techniques for testing AI systems
- 🛡️ Blue Teaming guidance — defensive strategies, detection, and hardening
- 📜 Compliance & Regulations — summaries of legal and regulatory frameworks
- ⚙️ Frameworks & Organizations — standards, initiatives, and industry bodies
- 📚 AI Security Intelligence — curated and structured security knowledge

## 🔄 Automatic Updates (every 24 hours)

This repository is automatically updated using GitHub workflows and sources to exteral GitHub repositories. What this means:
- 🔍 GitHub tools and projects are checked every 24 hours
- 📊 Maintenance signals such as new commits in the external repositories are consider to update the Sekai;Gate Wiki

Why we decided to auto-update?
- ✅ Actively maintained and relevant tools are highlighted
- ⚠️ Abandoned or outdated projects can be identified more easily

Thanks to this approach, users can quickly see what is still maintained and worth using, instead of relying on outdated or unverified references.
The goal is to reduce noise and focus attention on tools and resources that are actually alive and usable today.
